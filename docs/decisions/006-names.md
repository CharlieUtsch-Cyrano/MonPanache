# 006 — Names: MonPanache, and only MonPanache

**Date:** 2026-08-27 (repo renamed 2026-09-02) · **Status:** accepted

## Context

Naming sprawl (the Tools repo's disease) starts with a second name. The
product was named from Cyrano's dying line — *"mon panache"*, the part of
your work that is irreducibly yours.

## Decision

The product **and** the GitHub repo are **MonPanache**
(`CharlieUtsch-Cyrano/MonPanache`); tagline *"Know what needs you now.
Automate what repeats."* The npm package stays `cyrano-task-manager`, and
the old `Cyrano-Task-Manager` repo remains only as the secondary git remote.
No third name, ever. Logo direction: **not** Cyrano imagery — no plume,
feather, or quill.

## Consequences / revisit when

Docs and UI say MonPanache; only package manifests say
`cyrano-task-manager`. Revisit never — rename fatigue is the point of this
record.
